# BlackCore 1.0.2

**BlackCore** — современный терминал для Linux, разработанный на C++17 и Qt 6. Программа сочетает полноценную работу с командной строкой, удобный графический интерфейс и дополнительные инструменты для разработчиков.

Основная целевая система — **Linux Mint Cinnamon**.

## Возможности

- Поддержка ANSI-последовательностей, Unicode, кириллицы и 256 цветов.
- Работа с Bash, Zsh и другими совместимыми командными оболочками.
- Терминальные вкладки и разделение окна на панели.
- Рабочие пространства и восстановление предыдущей сессии.
- Прокрутка истории терминала, выделение, копирование и вставка текста.
- Командная палитра и библиотека сохранённых команд.
- История команд и поиск по выводу терминала.
- Настраиваемые темы оформления, цвета, шрифты и горячие клавиши.
- Боковая панель с инструментами быстрого доступа.
- Инструменты для работы с SSH, Git и проектами.
- Мониторинг системы, диагностика и уведомления.
- Импорт и экспорт настроек.

## Системные требования

- **ОС:** Linux Mint Cinnamon, Ubuntu 24.04 или совместимый дистрибутив Linux.
- **Архитектура:** x86-64 (amd64).
- **Графическая библиотека:** Qt 6.4 или новее.
- **Терминальная оболочка:** Bash, Zsh или другая совместимая оболочка.

Пакет DEB предназначен для систем с совместимыми версиями системных библиотек. Основная проверка выпуска 1.0.2 проводилась в Linux Mint.

## Установка

Перейдите в раздел **Releases** репозитория BlackCore и скачайте:

`blackcore_1.0.2_amd64.deb`

Откройте терминал в каталоге со скачанным файлом и выполните:

```bash
sudo apt install ./blackcore_1.0.2_amd64.deb
```

Пакет содержит собственную модифицированную библиотеку `libvterm`, необходимую для расширенной обработки истории терминала и автоматических переносов строк.

После установки BlackCore появится в меню приложений.

Запустить программу также можно командой:

```bash
blackcore
```

Проверка установленной версии:

```bash
blackcore --version
```

Ожидаемый результат:

```text
BlackCore 1.0.2
```

## Сборка из исходников

BlackCore использует **C++17, Qt 6, CMake и libvterm**.

Для стандартной сборки необходимы компилятор C++, CMake, инструменты разработки Qt 6, `pkg-config` и системная `libvterm`.

Пример сборки:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel 2
```

Исполняемый файл будет находиться по пути:

`build/blackcore`

### Расширенная версия libvterm

Для полной поддержки обработки автоматических переносов строк в истории терминала BlackCore 1.0.2 использует библиотеку из проекта:

https://github.com/neovim/libvterm

**Зафиксированный коммит:**

`934bc2fbf21800ac3458a499df8820ca5fb45fd3`

После сборки этой библиотеки необходимо обеспечить её обнаружение через `pkg-config` и включить расширенный режим:

```bash
cmake -S . -B build-extended \
  -DCMAKE_BUILD_TYPE=Release \
  -DBLACKCORE_ENABLE_VTERM_PUSHLINE4=ON
```

```bash
cmake --build build-extended --parallel 2
```

Этот режим требует совместимой библиотеки `libvterm` как при сборке, так и при запуске приложения. Если расширение `sb_pushline4` недоступно, CMake остановит конфигурацию.

Обычная сборка с системной библиотекой поддерживается, но может отличаться обработкой автоматических переносов строк в истории терминала.

## Безопасность и конфиденциальность

BlackCore работает локально и не требует регистрации или облачного аккаунта.

Настройки, история и журналы приложения хранятся на компьютере пользователя. Программа не предназначена для автоматической отправки этих данных на внешние серверы.

При работе с SSH используются системные инструменты.

## Удаление

Для удаления установленной программы:

```bash
sudo apt remove blackcore
```

Пользовательские настройки и журналы при обычном удалении пакета сохраняются.
